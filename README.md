# Ontology-perturbation pairwise annotation

`index.html` is one self-contained page: 20 DrugMechDB indications and 433 pairs of
perturbed mechanism paths, each shown with the LLM judge's verdicts and the OurEval
score. For every pair the annotator picks the better (or less bad) path, or marks both
good or both bad.

Annotations are saved in the browser (localStorage) under the annotator code on every
click. **Download** writes the JSON to send back, **Restore** reads it back, **CSV** is
for analysis. Use the same browser each time and download a backup regularly.

The page is generated by `scripts/build_onto_site.py` in `path_eval_new`.
